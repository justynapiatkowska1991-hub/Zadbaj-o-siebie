# Zadbaj o siebie 🌷

Aplikacja **Moja Chwila** do codziennego dbania o siebie.

## Funkcje
- codzienny nastrój i historia emocji,
- małe zadania z punktami,
- wyzwania i poziomy,
- ćwiczenie oddechowe,
- własne zadania,
- profil i lokalny zapis postępów.

Aplikacja działa po stronie przeglądarki i przechowuje dane lokalnie (`localStorage`).
